# Glossary

Domain terms used in specs and code. German terms keep their German name in code identifiers
only when there is no precise English equivalent.

| Term              | Meaning                                                             | Notes                                           |
| ----------------- | ------------------------------------------------------------------- | ----------------------------------------------- |
| Anmeldung         | Registration of residence at the local citizens' office (Bürgeramt) | Required within 14 days of moving in            |
| Entlastungsbetrag | Monthly relief amount from long-term care insurance (§45b SGB XI)   | Can fund recognised everyday support services   |
| REQ               | Requirement identifier in `docs/spec/`                              | Format `REQ-123`                                |
| DEC               | Decision identifier in the orchestrator's store                     | Promoted to an ADR or spec when it affects code |
