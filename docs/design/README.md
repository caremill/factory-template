# Design

Owned by the Designer.

- `tokens/` — design tokens (colours, spacing, typography) shared with the Tailwind config
- `screens/` — exported screens, one file per screen, named after its route
- `../../design/prototypes/` — clickable HTML + Tailwind prototypes, deployed with each preview

Every story with UI links its screens in the project's **Design link** field.
Accessibility target: WCAG 2.2 AA. Plain language for all core content.
